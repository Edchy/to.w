# Font licenses

The site's two typefaces come from Fontsource (npm), each package carrying its own license:

- Instrument Serif by Rodrigo Fuenzalida and Jordan Egstad (`@fontsource/instrument-serif`): display type. SIL Open Font License 1.1.
- IBM Plex Mono by IBM (`@fontsource/ibm-plex-mono`): text, and the poem engraved inside the 3D ring (`scripts/make-band-ring.mjs`). SIL Open Font License 1.1.

The TO·W wordmark (drawn inline in `src/components/site/Wordmark.astro`; source artwork in `unused/brand/`) and the other logo SVGs in `unused/brand/` contain letter outlines converted from Labrada by Mercedes Jáuregui and Omnibus Type (https://github.com/Omnibus-Type/Labrada), SIL Open Font License 1.1. The font itself is not bundled.
